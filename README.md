# AUTOFAST — главная страница (демо)

Лендинг для компании по импорту автомобилей из Китая, Кореи и Европы под ключ в Воронеж.

Чистый HTML/CSS/JS без сборки:

- `index.html` — разметка
- `assets/css/style.css` — стили (сетка 1240px / 12 колонок)
- `assets/js/main.js` — интерактив: слайдер, калькулятор, фильтры каталога, кейсы, FAQ, форма
- `assets/img/` — изображения (webp)

Форма, мессенджеры и «скачать PDF» работают в демо-режиме, данные никуда не отправляются.
Перед запуском убрать `<meta name="robots" content="noindex, nofollow">` и подключить реальные контакты.
